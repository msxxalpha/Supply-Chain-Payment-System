# سامانه مکانیزه تخصیص و پرداخت مالی تامین‌کنندگان ایندامین سایپا

این پروژه یک سامانه تحت وب برای مکانیزه‌کردن محاسبه و تخصیص بودجه پرداخت به تامین‌کنندگان زنجیره تامین است و با الگوی معماری Employee Performance System توسعه یافته است.

## معماری

- ASP.NET Core MVC روی .NET 10
- Entity Framework Core 10
- SQL Server
- ClosedXML برای ورود و خروجی Excel
- احراز هویت Cookie و نقش مدیر سامانه
- رابط فارسی RTL و تقویم شمسی
- ثبت Audit Log
- CI با GitHub Actions

## جریان کاری

۱. تعریف اطلاعات پایه: پارامترهای پرداخت، کالاها، تامین‌کنندگان، رابطه قطعه–تامین‌کننده و ارزیابی‌های قطعه–تامین‌کننده.
۲. ویزارد سه‌مرحله‌ای: تنظیم محاسبه، جذب Excel و محاسبه، سپس تجمیع تامین‌کنندگان و تایید نهایی.
۳. پس از تایید، ریز رسیدها و امتیازها به همراه snapshot مستقل خلاصه تامین‌کنندگان در دیتابیس ثبت می‌شوند.

## جلوگیری از پرداخت تکراری

کلید کسب‌وکار هر بدهی برابر چهار جزء «شماره رسید + انبار + کالا + تامین‌کننده» است. در هر محاسبه، مجموع تخصیص‌های تاییدشده قبلی برای همین کلید از بدهی ورودی کسر می‌شود. رسیدی که مانده آن صفر شود دیگر تخصیص نمی‌گیرد. برای شاخص دیتابیس، هش SHA-256 همین کلید نیز نگهداری می‌شود.

## امتیازدهی

مجموع وزن پارامترهای فعال باید دقیقاً ۱۰۰٪ باشد؛ در غیر این صورت محاسبه متوقف می‌شود.

سن بدهی موثر: کمتر از ۲۵٪ => ۱، از ۲۵٪ تا ۵۰٪ => ۲، بیش از ۵۰٪ تا ۷۵٪ => ۱، بیش از ۷۵٪ تا پایان مهلت و تا ۳۰ روز پس از آن => ۴، بیش از ۳۰ روز پس از مهلت => ۵.

مبلغ بدهی: کمتر از ۳٪ => ۱، ۳٪ تا ۱۰٪ => ۲، بیش از ۱۰٪ تا ۲۰٪ => ۳، بیش از ۲۰٪ تا ۳۵٪ => ۴، بیش از ۳۵٪ => ۵.

## نکته فرمول مبلغ تخصیص

فرمول «امتیاز وزنی × کل مبلغ قابل تخصیص» در صورت استفاده از امتیاز خام ۱ تا ۵، می‌تواند بودجه را چند برابر کند. برای اینکه «مبلغ کل قابل تخصیص» واقعاً سقف پرداخت باشد و بیش‌پرداخت رخ ندهد، سیستم بودجه را متناسب با امتیاز وزنی بین رسیدها توزیع می‌کند و سقف هر رسید را مانده بدهی همان رسید قرار می‌دهد.

## نصب

۱. فایل Database/001_initial.sql را روی SQL Server اجرا کنید.
۲. ConnectionStrings:Default و InitialAdminPassword را برای محیط اجرا تنظیم کنید.
۳. پروژه را با .NET 10 اجرا کنید:

    dotnet restore Indamin.Payment.Web.csproj
    dotnet build Indamin.Payment.Web.csproj
    dotnet run --project Indamin.Payment.Web.csproj

حساب اولیه مدیر: admin. رمز اولیه از InitialAdminPassword خوانده می‌شود.

## CI و تست

فایل .github/workflows/build-and-test.yml در Push به main، restore، build و unit test را اجرا می‌کند. تست‌های واحد در SupplyChainPaymentSystem.Tests قرار دارند.
